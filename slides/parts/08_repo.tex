\begin{frame}[fragile]{Everything here is reproducible}
  \begin{columns}[T]
    \begin{column}{0.5\textwidth}
      \small
      \textbf{Package} \texttt{stochastic\_risk}, NumPy and SciPy only: \texttt{measures}, \texttt{volatility}, \texttt{evt}, \texttt{backtest}, \texttt{model\_risk}, \texttt{credit}, \texttt{pd\_validation}, \texttt{ccr}, \texttt{montecarlo}, \texttt{oprisk}, \texttt{stress}.
      \vspace{0.3em}

      \textbf{Tests} (24): each closed form or estimator against an independent result.

      \textbf{Experiments} (19): each has a compute step that saves raw arrays and a plot step that writes the figure and the numbers these slides read.

      \textbf{Gallery and animations}: one showcase figure per topic and five GIFs of the simulations in \texttt{figures/}.
    \end{column}
    \begin{column}{0.46\textwidth}
      \scriptsize
\begin{verbatim}
pip install -e ".[test]"
python -m pytest tests
cd experiments
python run_all.py --compute --jobs 16
python run_all.py --plot
cd .. && python build_slides.py
\end{verbatim}
      \small
      Fixed random seeds. The compute step is about half an hour of CPU time; on a 16-core cluster node it took eight minutes.
    \end{column}
  \end{columns}
\end{frame}
